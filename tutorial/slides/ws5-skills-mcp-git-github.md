# Workshop 5: Skills, MCP, Git und GitHub

> Versionskontrolle verstehen, Claude Code mit Skills und MCP erweitern, und ein Blick unter die Haube: was ein Sprachmodell zum Agenten macht – der fünfte Workshop im Legal History Hub Projekt.

**Datum:** 12.06.2026
**Dauer:** 4 Stunden (Remote)
**Leitung:** Christian Steiner

## Themen

- Was ist Git und wozu braucht man das: Versionskontrolle, Zeitreise, Zusammenarbeit ohne Überschreiben
- Git-Grundbegriffe: Repository, Clone, Staging, Commit, Push, Pull, Branch, Merge, Pull Request
- Git lokal vs. GitHub remote – und warum Coding Agents ständig mit Git arbeiten
- Was ist ein AI-Harness: die Architekturschicht, die ein Sprachmodell zum Agenten erweitert (Loop, Tools, Memory, Permissions, Hooks)
- Die Computer-Analogie: Harness = Betriebssystem, Modell = CPU, Context Window = RAM, Agent = Anwendung
- Die Coding-Agent-Landschaft: Claude Code, GitHub Copilot, OpenAI Codex, Gemini CLI, Cursor und Co.
- Agent Skills: wiederverwendbare Fähigkeiten für Agenten, das `/skills`-Menü in Claude Code, agentskills.io
- Use Case live: Meeting-Protokoll-Workflow als Custom Skill (Transkript → `/meeting-protokoll` → Markdown → Word, OneNote, PDF)
- Der Promptotyping-Skill: die Projektmethodik als installierbarer Skill ([GitHub-Repo](https://github.com/DigitalHumanitiesCraft/promptotyping-skill))
- Model Context Protocol (MCP): der offene Standard, der LLM-Anwendungen mit Werkzeugen und Datenquellen verbindet
- MCP-Grundbausteine (Tools, Resources, Prompts), die USB-C-Analogie, MCP-Server in Claude Code (Gmail, Calendar, Drive, PubMed)
- Dynamische `/workflows`: Multi-Agent-Läufe in Claude Code live
- Advanced Topics: Wissensorganisation mit Markdown ([Obsidian](https://obsidian.md/)), Dateitransformation PDF → Markdown ([Docling](https://www.docling.ai/))
